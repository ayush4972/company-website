Useful to know

Before we talk.

Do I need a detailed project brief?

No. Start with the problem and who experiences it. If you already have designs, a brief, or an existing system, mention those in your message.

Can you improve an existing product?

Yes. We can discuss the current experience, technical constraints, and the changes that would make the biggest difference.

Is this the place to report a road issue?

For road reports, use the Sadak Sujhav app so you can attach a photo, confirm the location, and follow the report in the proper workflow.
