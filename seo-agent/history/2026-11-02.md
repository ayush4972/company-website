## Pattern notes

1. **The PR backlog problem isn't solved, it's cyclical, and it has a new failure mode.** The
   5-PR pile from September did clear, in one batch, after nearly three weeks. A new pile of
   comparable size built right back up in October. And this run shows the pile isn't just a
   review-lag annoyance — if `main` moves far enough while PRs sit unreviewed, the PRs themselves
   go stale and need to be redone, which is strictly worse than reviewing them promptly would
   have been. The redesign didn't just block new on-page audits (like 2026-10-05's observation)
   — it broke old open PRs outright.
2. **Search visibility has now been zero for eight consecutive runs, across a complete site
   redesign.** That's a meaningful negative result: the "maybe the old design/markup is the
   problem" hypothesis is now effectively ruled out, since a ground-up rebuild changed nothing.
   The remaining live hypotheses — GSC was never connected to actually check indexing status,
   the backlink/social-presence gap, and the press-attribution gap — are all off-page or
   tooling issues, not on-page ones. On-page SEO has been clean (titles/descriptions aside, which
   this run just fixed again) for most of this run's history; it is very unlikely to be the
   blocker.
3. A large non-agent redesign PR can regress prior agent work silently (JSON-LD, in this case).
   Worth a standing checklist item for any future run that detects a big diff on `main` since
   last audit: re-check that prior fixes (schema, meta tags) are still present, not just that new
   content is clean.
