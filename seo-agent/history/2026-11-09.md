## Pattern notes

1. **The "stale PR" failure mode is now confirmed recurring, not a one-off.** First seen
   2026-11-02 (redesign broke #10/#12), now seen again 2026-11-09 (a smaller QA commit broke
   #17/#18) — same mechanism both times: a correct fix sits open long enough for unrelated
   `main` activity to invalidate its diff, and the fix has to be fully redone rather than simply
   merged. The fixes themselves have been right both times; only review latency causes this.
   This is now the single most concrete, actionable process finding from ten runs — more
   specific than "PRs aren't getting reviewed," because it quantifies the actual cost of the
   delay (full rework, not just a wait).
2. **Search visibility has now been zero for nine consecutive runs**, spanning a full site
   redesign and two further rounds of unrelated site changes. On-page SEO has been clean (aside
   from the two regressions this run re-fixed, both caused by unrelated work, not by anything
   wrong with prior SEO fixes) for the entire stretch. GSC access remains the one thing that
   could turn nine runs of "still zero, still unmeasured" into an actual diagnosis.
3. The methodology lessons from 2026-09-28 (characters, not bytes) and 2026-11-02 (verify merge
   status with a real test-merge, not the cached flag) both proved their worth again this run.
   Adding a third to the list: parse `<meta>` tag attributes order-independently, since relying
   on a fixed `name=`/`content=` order silently miscounted several pages' descriptions as
   missing this run until caught and corrected before anything was proposed.
