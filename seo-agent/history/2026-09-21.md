## Phase 2 — Research

Web search only (no GSC). This is where the interesting finding is.

- **Search visibility is still effectively zero.** `"Trasier Technology"`, `"trasiertech.com.np"`,
  and `site:trasiertech.com.np` all still return **no results referencing the company or its
  domain** — one week after last run's fixes merged. Instead, the exact-brand query surfaces
  orthographically similar but unrelated companies: **Trasier** (a distributed-tracing tool at
  trasier.com), **Tradier**, and **Traser** (a watch brand). This wasn't visible as a distinct
  problem last week because there was no search presence at all to compare against; now that
  there's real content to search for, the name-collision issue is clearer: even once indexed,
  Trasier Technology will be competing directly against similarly-spelled, already-established
  domains for its own brand query.
- **Major new development: the product launched publicly and got real press coverage.** Sadak
  Sujhav's September 17, 2026 rollout with Road Division Kathmandu was covered by at least 20
  outlets — OnlineKhabar, Ratopati, The Himalayan Times, Nepal News, ICTFrame, Nepal Press,
  Khabarhub, NepalAuto, and others (English and Nepali). Searching `"Sadak Sujhav"` now reliably
  surfaces this coverage.
- **But the coverage doesn't credit Trasier Technology.** Checked multiple articles' search
  snippets and cross-referenced queries combining "Trasier" with each outlet name — the press
  framing is uniformly government-led ("Road Division Kathmandu... launched the app"), and no
  article turned up in search naming Trasier Technology as the builder. This is a more specific
  version of last week's "zero backlinks" finding: it's not just that nobody has linked to the
  site yet — the one big off-page event since then didn't generate brand citations either,
  because the press wasn't given (or didn't use) the company's name. That's a PR/media-relations
  gap, not a code fix, but it's worth flagging explicitly since it changes the shape of the
  backlink recommendation from last week (see Phase 3).
- No LinkedIn, GitHub, Twitter/X, Facebook, or Instagram presence found — same as last week.
  Still nothing in the site's own footer/nav linking to any social profile.
- Search Console remains disconnected in this environment; recommendation to reconnect it
  stands from last run.

## Pattern notes

The clearest pattern isn't about which on-page fix worked yet — there's still no outcome data
for any of them. It's that **the site's off-page/indexing problem is proving more stubborn than
"new site, give it time."** A week ago the working theory was that zero backlinks + zero social
presence explained zero search visibility. This week, the product got substantial, genuine press
coverage — and search visibility is still zero, because that coverage didn't name the company.
That's a sharper, more specific problem than "build some backlinks eventually": the backlink
opportunity already happened once and was missed on the attribution side, not the volume side.
Future runs should watch for (a) whether GSC ever gets connected, since that's the only way to
get real indexing-status ground truth instead of inferring from search result absence, and
(b) whether any future press cycle (there will likely be more, given the blog's cadence) actually
credits Trasier Technology by name — that's the signal that the comms-side fix in Phase 3 is
being acted on, separate from anything this agent can push code for.
