# Trasier website — 2026 redesign

This local redesign adapts the editorial design-token structure and frontend craft guidance from [Open Design](https://github.com/nexu-io/open-design). Reference: `design-systems/editorial/` and `skills/frontend-design/`. Implementation is original except the attributed vendor tokens. See `docs/third-party/`.

## Direction
Human, useful technology built in Nepal. Airy white backgrounds, powder-blue surfaces, navy type, and clear blue accents form a lighter blue-and-white theme. The homepage introduces Trasier first through an interactive, sculptural 3D T representing digital products, intelligence, and connected systems. Company capabilities and approach lead into selected work, where visitors discover Sadak Sujhav. Use the transparent version of the supplied Trasier owl logo, maintaining its blue-and-navy identity without a background tile, shadow, rounded frame, or cropping. Real product and road photography belong to the project discovery and product pages. Avoid custom cursors, decorative operational dashboards, and unsupported impact metrics.

## Shared implementation contract
- Every page loads `/css/site.css` and deferred `/js/site.js` (relative paths allowed for static hosting). `/css/theme.css` is the final stylesheet after page-specific styles and owns the current palette.
- `<body data-page="home|product|work|services|company|journal|contact|careers|legal">`.
- Insert `<div data-site-header></div>` before `<main id="main-content">`; `<div data-site-footer></div>` after main. site.js owns accessible header/footer and active navigation.
- Use root-relative internal paths (server root is frontend). Existing URLs must remain available.
- Icons use `<svg ...>` inline or `[data-icon="arrow-up-right|arrow-right|... "]`; site.js renders data-icon placeholders. Text labels always accompany action icons.
- Shared CSS classes: `.container`, `.section`, `.section-sm`, `.eyebrow`, `.muted`, `.accent`, `.section-heading`, `.section-intro`, `.button` (`.button-primary`, `.button-dark`, `.button-outline`, `.button-light`, `.button-small`), `.text-link`, `.pill`, `.tag`, `.page-hero`, `.breadcrumb`, `.split`, `.grid-2`, `.grid-3`, `.card`, `.card-icon`, `.card-link`, `.feature-list`, `.process-grid`, `.process-step`, `.cta-band`, `.dark-section`, `.paper-section`, `.prose`, `.article-layout`, `.article-header`, `.article-meta`, `.image-frame`, `.caption`, `.faq-list`, `.source-note`, `.source-list`, `.form-grid`, `.field`, `.form-status`, `.contact-layout`, `.contact-aside`, `.check-list`.
- `.section-heading` is a flex row with h2/intro or action. `.split` and `.grid-2` are 2 equal columns; `.grid-3` 3 columns. Collapse automatically on mobile.
- `.page-hero` contains `.container`, breadcrumb, eyebrow, one h1, and intro paragraph. Content max-width and typography are built in.
- `.card` is a padded white surface with high-contrast navy text, `.card-icon` a square powder-blue icon treatment. `.feature-list` is an unstyled list with border rows. `.process-step` contains a step number span, h3, paragraph.
- Contact form: id `contact-form`, fields name/email/message, status id `contact-form-status` with role status, submit button. site.js handles submit, honest local backend errors, reset, pending state.
- Careers form: id `careers-form`, fields name/email/expertise/cv file; optional 3 MB CV. status id `careers-form-status`. site.js handles /api/careers.
- Interactions must work without external JS dependencies; body text visible before JS; details/summary for FAQ; semantic headings, labels, alt text, keyboard focus, reduced-motion support.

## Motion
Shared 650 ms native browser entrances, triggered once by IntersectionObserver, live in `frontend/js/motion.js` and `frontend/css/motion.css`. They move small text blocks by eight pixels without stagger delays. Initially visible content and large artwork stay static. This module has no scroll/resize listener, reading-progress painting, or animation-frame loop. Reduced-motion changes cancel active reveals; keyboard focus, anchors, and printing reveal content immediately.

The hero preserves its two masked headline lines, underline draw, and softly drifting blue background. `hero-motion.js` uses anime.js's native WAAPI backend with direct transform keyframes; no JavaScript ticker drives these effects. Lines rise for 1100 ms with a 200 ms stagger, then the underline draws for 650 ms after an 80 ms pause. Two soft radial layers drift by at most 12 px over 24/29 seconds and pause offscreen or when hidden. Masks reserve their full layout space and have enough ink/underline bleed for mobile. Focus, anchors, printing, and reduced motion settle the text immediately. The typography divider uses a CSS view timeline to follow scrolling directly, with no competing JavaScript driver.

The company landing in `company-home.css`, `company-scene.css`, and `company-scene.js` uses locally vendored Three.js for a rounded, polished blue T sculpture. Three semantic buttons change the form and introduce real service categories; their corresponding links remain normal anchors. The canvas is decorative and excluded from generic reveals. A static SVG keeps the composition complete while loading or when WebGL is unavailable. Pointer response is limited to fine pointers; rendering stops when settled, offscreen, hidden, or printing. Mode transitions last 560 ms and finish uninterrupted during scrolling. Pixel ratio is capped at 1.25, shadows use a 512 px map, and materials avoid transmission passes. Product screenshots and road imagery do not appear in the company hero. Pinned source and MIT notices live in `docs/third-party/threejs/`.

The retained native scene primitives in `creative-motion.js` adapt Hyperframes' orbital/camera math, with pinned originals and Apache notices in `docs/third-party/hyperframes/`. They load only where their markup is present; the homepage divider uses a CSS view timeline. No video-rendering pipeline or CDN script is needed.

Shared creative controls use `creative-buttons.css` and `creative-buttons.js`: blue capsules, circular arrow caps, a local spotlight, and anime.js arrow gestures, press feedback, and click ripples. Hit targets and labels stay fixed. Form controls retain their labels and native submit flow. Reduced motion receives immediate static feedback. The homepage's kinetic divider and editorial service rows belong to the same route-and-signal visual language. Its capability buttons update the content and links immediately, then animate the summary with a short stagger while the sculpture changes form. The outlined “View work” button offers a direct route to selected work.

`depth-scenes.js`/`.css` carries fine-pointer depth and subtle scroll parallax into the product and case-study preview imagery. Additive native view-timeline transforms preserve the original rotations and run independently of pointer transforms. The compatibility path uses cached geometry and a single passive frame; it does not repeatedly measure layout during scrolling. Combined movement stays under six pixels/three degrees, and captions and controls never move. Coarse pointers, hidden scenes, printing, and reduced motion receive static imagery. Sticky header and case navigation use solid backgrounds without backdrop blur.
